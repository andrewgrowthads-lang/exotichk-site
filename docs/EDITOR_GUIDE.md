# Гайд для редактора (Sanity Studio)

Короткая инструкция для человека без технического опыта. Технические решения — в `docs/ARCHITECTURE.md`.

## Как открыть Studio

- Локально (для разработчика): `npm run sanity:dev`, откроется на `http://localhost:3333`.
- После `npm run sanity:deploy` появится постоянный адрес вида `https://<project>.sanity.studio` — именно его стоит использовать в работе, чтобы не держать компьютер разработчика включённым.

## ⚠️ Важно: сначала «заберите» проект

Проект Sanity сейчас создан автоматически и никому не принадлежит («unclaimed»). В этом состоянии **загрузка фотографий не работает** — это ограничение самого Sanity для незаявленных проектов, не баг сайта. Все остальные поля (текст, страна, район, статус и т.д.) работают уже сейчас.

Чтобы включить загрузку фото, нужно один раз «заявить» проект на свой аккаунт Sanity — при первом открытии Studio (или по ссылке, которую показывает `npm run sanity:deploy` / `sanity manage`) появится предложение привязать проект к вашему логину. После этого шага фото начинают работать как обычно.

## Основной сценарий: добавить новую анкету

1. В левом меню откройте **Profile** → кнопка **+ New Profile** (или «Profile» в списке типов документов).
2. Вкладка **Content**: имя для себя (Internal ID), отображаемое имя, страна, район, статус (по умолчанию Active).
3. Вкладка **Photos**: главное фото (Main photo) — обязательно для активной анкеты, и дополнительные фото (Gallery).
4. Вкладка **Details**: возраст, рост, национальность, языки, короткое и полное описание, доп. характеристики (теги).
5. Вкладка **Contact** — только если нужно переопределить Telegram/WhatsApp именно для этой анкеты. Если оставить пустым, используются общие контакты из **Site settings**.
6. Вкладка **SEO** — трогать не обязательно, там разумные значения по умолчанию (название страницы = отображаемое имя).
7. Нажмите **Publish**.

После публикации анкета сама появляется на сайте — на главной, на странице страны и района, без участия разработчика. Обновление занимает до часа автоматически (или мгновенно, если настроен webhook — см. `docs/ARCHITECTURE.md`, раздел 7).

## Статусы анкеты

- **Draft** — это не значение поля, а просто «не нажимать Publish». Черновик не виден на сайте.
- **Active** — обычная опубликованная анкета.
- **Temporarily unavailable** — анкета остаётся на сайте (не теряет позиции в поиске), но помечена как временно недоступна.
- **Archived** — анкета убирается со всех страниц и из поиска. Старую ссылку на неё сайт вернёт как «страница не найдена».

## Site settings

Один общий документ (не список) — открывается отдельным пунктом сверху меню:

- **Brand** — название и описание агентства, логотип.
- **Contact** — WhatsApp, Telegram (менеджер), Telegram-канал. Это значения по умолчанию для всех анкет.
- **Social** — заголовок/описание для соцсетей и картинка для превью, если у анкеты своей нет.

## Country / District

Используются, чтобы у анкеты был раздел на сайте. Добавлять новую страну или район — тот же принцип: **+ New**, заполнить название и вступительный текст на английском (китайский — по желанию), Publish.

Страну или район нельзя архивировать, пока к ним привязана хотя бы одна неархивированная анкета — Studio покажет ошибку с указанием, что нужно сделать сначала.
