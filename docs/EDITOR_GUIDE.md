# Гайд для редактора (Sanity Studio)

Короткая инструкция для человека без технического опыта. Технические решения — в `docs/ARCHITECTURE.md` и `docs/MULTI_COUNTRY.md`.

Studio: https://exotichk-admin.sanity.studio/

## Меню слева

- **Profiles** → выберите страну (Hong Kong / Singapore) → анкеты только этой страны.
- **Districts** → выберите страну → районы только этой страны.
- **Country settings** → настройки страны: контакты менеджера, фон, тексты, валюта.
- **Site settings** — общие настройки бренда (название, описание, логотип, картинка для соцсетей).
- **All profiles / All districts** — общие списки всех стран (для поиска и архива).

## Добавить анкету

1. **Profiles** → нужная страна → кнопка **+** (создать). Страна подставится сама.
2. Заполните сверху вниз: **Country** (уже выбрана), **Name**, **District** (в списке только районы выбранной страны), **Age**, **Height**, **Nationality**, **Languages**, **Price** (только цифры — валюта показана слева: HK$ или S$), **Description**, затем **Photos** (можно выбрать сразу несколько файлов).
3. Нажмите **Publish Profile** (переводит на китайский, если перевод доступен, и публикует) или **Publish English only**. Пока в анкете есть красные ошибки (нет имени, района, фото и т. п.), кнопки публикации неактивны — список ошибок открывается значком ⓘ вверху справа. Это касается и кнопки **Publish** у стран, районов и Site settings.

Сайт обновляется сам в течение нескольких секунд. Ссылка анкеты (slug) и внутренний номер создаются автоматически.

После публикации **страну анкеты изменить нельзя** (у анкеты изменился бы адрес). Если анкета переезжает — создайте новую в другой стране, а старую архивируйте.

Если у страны ещё нет контактов менеджера, Studio покажет жёлтое предупреждение: анкету опубликовать можно, но кнопок связи на ней не будет, пока контакты не добавлены.

## Статусы анкеты

- **Draft** — это не значение поля, а просто «не нажимать Publish». Черновик не виден на сайте.
- **Active** — обычная опубликованная анкета.
- **Temporarily unavailable** — анкета остаётся на сайте (не теряет позиции в поиске), но помечена как временно недоступна.
- **Archived** — анкета убирается со всех страниц и из поиска. Старая ссылка вернёт «страница не найдена».

## Изменить контакты страны (WhatsApp / Telegram)

1. **Country settings** → нужная страна → вкладка **Contacts**.
2. Поля: **WhatsApp manager** (`https://wa.me/…`), **Telegram manager** (`https://t.me/…`), **Telegram channel** (необязательно).
3. **Publish**. Сайт обновится сам, без разработчика.

Контакты каждой страны независимы: пустое поле означает «кнопку не показывать». Контакты Гонконга **никогда** не подставляются в Сингапур. У отдельной анкеты можно задать свои контакты, но обычно это не нужно.

## Добавить район

1. **Districts** → нужная страна → **+**.
2. **Title** (название на сайте, например *Orchard*), **Internal name** (обычно то же), **Slug** — кнопка **Generate**, **Intro** (одно предложение).
3. **Publish**.

Вкладка района появляется на сайте только когда в нём есть хотя бы одна видимая анкета. Вкладка **ALL** есть всегда.

## Фон страны

**Country settings** → страна → вкладка **Background** → **Background image**. Если оставить пустым, используется встроенное фото ночного города (Гонконг — гавань, Сингапур — Marina Bay).

## Site settings

- **Brand** — название и описание агентства (описание показывается на странице выбора страны — пишите его для обеих стран), логотип.
- **Social** — заголовок/описание страницы выбора страны и картинка для превью в соцсетях.
- **Legacy contacts** — старые общие контакты, только для чтения. Контакты теперь редактируются в **Country settings**.

## Архивирование страны или района

Страну или район нельзя архивировать, пока к ним привязана хотя бы одна неархивированная анкета — Studio покажет ошибку с указанием, что нужно сделать сначала.

## Китайская версия

Сингапур запущен только на английском: китайских страниц у Сингапура нет, и на китайской версии сайта карточка Сингапура ведёт на английскую страницу. Китайская версия Сингапура появится, когда у страны и её районов будут китайские названия и тексты (разработчик проверит перед включением).
